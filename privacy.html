Privacy

Verrassend Zweden gebruikt geen cookies, geen statistieken en geen software die bezoekers volgt.

Hosting

Verrassend Zweden staat op GitHub Pages. GitHub kan daarbij het IP-adres van bezoekers vastleggen. Wat GitHub precies doet, staat in de documentatie van GitHub Pages.

Wisselkoers

In de voettekst staat de actuele koers van de euro en de Zweedse kroon. De browser van de bezoeker haalt die op bij de gratis dienst Frankfurter (api.frankfurter.dev). Daarbij worden het IP-adres en de gebruikelijke technische gegevens van de browser zichtbaar voor die dienst. Lukt het ophalen niet, dan probeert de browser een reserveadres van dezelfde dienst (api.frankfurter.app). Hoe Frankfurter met gegevens omgaat, staat onder ‘Hoe zit het met privacy?’ op de pagina van Frankfurter. De koers zelf is een referentiekoers van de Europese Centrale Bank.
